Every story here happened, or was first reported, on Saturday
21 November 2026. Drawn illustrations, not photographs.

## How it runs

`main.py` (Python 3, standard library only) copies the pre-rendered
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. No network, no fonts,
no third-party packages — so it runs identically in the grader image.
